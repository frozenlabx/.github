# FrozenLab Organization Health & Profile Repository

This repository contains organization-wide community health files and the official organization profile for **[FrozenLab](https://github.com/frozenlabx)** (`frozenlabx`).

## Contents

- **`profile/README.md`**: The public-facing organization profile page rendered at `https://github.com/frozenlabx`.
- **`.github/ISSUE_TEMPLATE/`**: Standardized GitHub Issue Forms (`bug_report.yml`, `feature_request.yml`, `config.yml`).
- **`.github/PULL_REQUEST_TEMPLATE.md`**: Default Pull Request checklist and review guidelines for repositories across FrozenLab.
- **`SECURITY.md`**: Organization-wide vulnerability disclosure and reporting policy.
- **`CODE_OF_CONDUCT.md`**: Contributor Covenant Code of Conduct.
- **`CONTRIBUTING.md`**: General contribution guidelines for all FrozenLab open-source projects.
- **`LICENSE`**: MIT License.
