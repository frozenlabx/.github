# 🔐 Security Policy

At **FrozenLab**, we take the security of our open-source software and the developers who depend on it seriously.

---

## 🛡️ Supported Versions

We provide security updates for the current major/minor versions of our active packages:

| Project | Supported Versions |
| :--- | :--- |
| `ui_guard` | `1.x.x` |

---

## 🚨 Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

If you discover or suspect a security vulnerability in any FrozenLab project, please report it privately through one of the following methods:

1. **GitHub Private Vulnerability Reporting** (Preferred):
   - Go to the **Security** tab of the affected repository.
   - Click **Report a vulnerability** to open a private advisory draft with maintainers.

2. **Email Disclosure**:
   - Send an email to **`security@frozenlab.dev`** (or directly contact **MD. Tanvirul Islam** via [tanvirdev.com](https://tanvirdev.com)).
   - Include:
     - The repository name and affected version(s).
     - A detailed description of the vulnerability.
     - Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
     - Potential impact of exploitation.

---

## ⏱️ Response & Disclosure Process

1. **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
2. **Investigation & Triage**: Maintainers will investigate, reproduce, and determine the severity.
3. **Fix & Patch**: A fix will be developed and verified in a private branch or advisory.
4. **Public Release & Advisory**: A patched release will be published along with a credit to the reporter (unless anonymity is requested).

Thank you for helping keep FrozenLab and the open-source community safe!
